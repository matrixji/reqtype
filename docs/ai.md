# 可选 AI 辅助

在文档中选择文字，或点击条目的浮动 tip 后，使用“AI 辅助”。未选择文字时，已选条目的完整正文作为输入；没有选区或条目时，可仅填写指令来生成草稿。发送前，面板明确显示将发送的原文和字符数。

## 三种任务

- **润色选中文字**：先生成候选内容，显示原文与候选的差异。可以编辑候选，再点击“应用润色”。只替换捕获的原选区，不改其他正文或元数据。
- **生成需求草稿**：候选内容是 Markdown 正文；用户填写标题、选择项目已有类型，再创建条目。应用生成 UUID 与项目内唯一编号，使用项目的初始状态和默认优先级。模型不分配身份、编号或批准状态。
- **检查需求质量**：列出歧义、完整性和可验证性建议，仅供阅读，不提供直接替换原文的操作。

生成、预览和保存是不同操作。生成不会修改文档；应用进入同一编辑历史，可撤销；磁盘写入仍需要保存。请求之后若文档已变化，原结果不能覆盖当前编辑；请重新生成或手动复制需要的部分。已有磁盘冲突会阻止应用，保存时仍检查文件内容版本。不能选择 front matter、req 元数据或跨越条目标签。

## 配置自己的服务

AI 默认关闭，不配置也能继续编辑、查询、Git、导入导出和本地图表渲染。设置位于“AI 辅助 → AI 服务设置”。

| 设置 | 含义 |
| --- | --- |
| 启用 AI | 仅启用可选命令；打开项目不会自动发送请求 |
| Base URL | 包含服务路径，例如 `https://api.example.com/v1` 或 `http://127.0.0.1:8000/v1`；会在后面追加 `/chat/completions` |
| 模型名称 | 填写服务实际提供的模型 ID，不固定型号，不自动联网查询模型列表 |
| API Key | 鉴权服务需要时填写；无需鉴权的本机服务可以留空 |

支持 HTTPS 以及本机 localhost／127.0.0.1／IPv6 loopback 的 HTTP。地址不能携带用户密码、查询参数或片段。修改服务地址会清除旧地址的已保存凭据，需要时重新填写。密钥输入框留空表示保留同一服务的旧凭据，勾选“清除”可显式移除。

首期协议为 **Chat Completions + SSE**，也接受兼容服务忽略 `stream` 后返回的完整 JSON。Responses API 的事件格式不同，后续可通过 `AIProvider` 单独适配，当前未实现 Responses、工具调用、联网搜索、自动执行或整项目上传。[OpenAI 官方流式文档](https://developers.openai.com/api/docs/guides/streaming-responses)

## 本机状态与凭据

配置保存在应用 userData 的 `ai-settings.json`，使用 `reqtype.ai` v1 信封。它独立于项目，不进入 Git、原生交换包、插件快照或发行包。凭据由 Electron 主进程调用系统安全存储加密后持久化；读取设置仅返回“是否保存凭据”，不回传保存后的明文。不具备系统安全存储时拒绝持久化密钥，可以使用无需鉴权的本机服务。

渲染进程通过限定的 IPC 启动／取消请求，HTTP 和凭据解密在主进程执行。未知版本或损坏的设置保留原文件并提示，不能自动当作首次使用重置。插件没有 AI 凭据读取入口。

## 失败与取消

请求只发送面板显示的文字、本次指令和内置任务提示，不自动读取其他项目文件或附件。正文最多 64000 字符，指令最多 4000 字符，输出最多 64000 字符；请求超时为 120 秒。

支持取消、关闭面板取消及切换项目取消。流式未完成、服务截断输出、超时或错误时不允许应用部分结果。不会自动重试或跟随重定向；错误提示不包含请求正文或凭据。服务返回 token 用量时显示实际值，缺失时不估算费用。

测试使用本机模拟服务验证协议与界面，不需要真实 API Key，也不证明某个远程服务的所有扩展参数兼容。对应实现为 `src/core/ai.ts`、`src/main/ai-*.ts` 与 `src/renderer/AIPanel.tsx`。
