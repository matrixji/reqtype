## 新模型回归

- 独立 `title` 优先于正文推导标题；标题补丁保留 UUID、正文、BOM／CRLF；留空可回退。表格按部分标题匹配，关联候选提供标题／编号过滤。CSV 增加标题列。
- 条目编号只读，新建／复制按项目前缀自动生成；主进程阻止跨模块重复、非法新前缀及已有编号改写，导入也保护当前已存在编号。原生交换保留合法历史编号。
- 项目设置支持两种本地类型套餐、自定义类型、在用数量和删除保护。真实桌面跨两个模块将全部“产品需求”迁移为 Story，逐字节核对只替换类型源字段，之后才允许删除原类型。
- 文本、数值与数组用表单定义及填写，按条目类型选择可用属性。数值有限性、数组元素类型、在用定义／绑定删除和改变类型导致的无效值均有校验；无效高级 JSON 定义只报错，不破坏表单；高级 JSON 与旧布尔值／枚举保留。
- 迁移预览零写入，绑定配置及完整文档清单，外部编辑、新增文件、跨项目和过期拒绝；注入多文件写入故障时回滚。目标未启用的原属性保留并提示。
- 项目 v1→v2 为原全局属性建立等价类型绑定。桌面实际执行检查、升级和恢复为 v1，核对项目身份与文档字节不变；保留历史 v1 Schema／夹具，新增 v2 Schema 与未来 v3 夹具。

用例与编号见[回归矩阵](regression-cases.md)，使用与来源见[条目模型说明](project-item-model.md)。两张发行包截图已经人工核对，展示套餐和属性表单。

## 限制

项目配置升级为 v2 后，旧版应用会拒绝该项目。旧项目需在新版“项目设置 → 数据格式与迁移”中显式升级，才能使用按类型属性与数组；不自动替用户升级当前工作区。

编号约束针对本应用保存／导入的项目数据；用户在外部编辑器或 Git 合并中仍可能制造无效数据，应用会诊断或拒写。本轮未验证多个应用进程同时写同一项目的隔离能力。

Windows 实机、系统输入法、大规模数据性能、进程强杀／断电场景仍待专项验证。发行包尚未签名／公证，构建仍有前端块体积提示。ASPICE 套餐是参考映射，不是过程认证或标准规定的默认类型清单。
