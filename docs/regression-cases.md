# 回归用例矩阵

行为变更与对应用例一起维护，先保留可复现的输入，再断言业务结果、未变数据与失败后的状态。下列编号是稳定的验证入口；自动化代码是执行依据，验证记录说明实际执行环境和结果。

## 执行方式

```sh
npm test
npm run test:e2e
npm run data -- check /path/to/project
```

发行包复用同一套桌面用例：设置 `REQTYPE_E2E_EXECUTABLE` 为发行包内可执行程序的绝对路径，运行 `npx playwright test`；每次启动会确认打包状态和应用版本。

核心检查不启动桌面；桌面流程启动真实 Electron，使用独立临时项目和 userData，结束后清理。CLI 的 `check` 不执行启动恢复，也不写入文件。Schema 的 `$id` 仅用于本地注册，测试不联网取 Schema。

## 格式契约与迁移

| 编号 | 场景与验收结果 |
| --- | --- |
| FMT-001 | 各数据域独立定版本；项目兼容 v1 与 v2；显式未来版本、字符串及非法版本拒绝；旧配置的安全缺省值与未知字段保留 |
| FMT-002 | 冻结无版本模块转换为 v1，逐字节比较 BOM、CRLF、注释、未知字段；UUID、编号、关联和正文不变；重复执行无修改 |
| FMT-003 | 未来模块只读、不进入旧版需求索引；属性补丁、模块补全和迁移均拒绝；其他 YAML 错误不能绕过版本保护 |
| FMT-004 | 旧裸设置／日志兼容读取；新信封保留根字段与 payload 扩展；未知格式标识和未来版本拒绝 |
| FMT-005 | 恢复日志在触碰目标文件前校验状态、路径、Base64 和哈希 |
| FMT-006 | 冻结交换包可读；未来版本与非法条目结构拒绝 |
| FMT-007 | 合成测试格式 1→2→3 按序逐步校验；转换确定、当前格式无操作；不表示已存在业务 v2 |
| FMT-008 | 步骤缺口、重复步骤、跨版本跳跃、错误输出和目标校验失败不会成功 |
| FMT-009 | 最近项目／插件启用状态兼容真实旧布局，保留扩展；未来状态不得写回 |
| MIG-001 | 预览零写入；普通 Markdown 不分配身份；不产生备份和新日志 |
| MIG-002 | 首次目标写入前备份已含全部原文；项目配置按契约升级，附件原字节保留，恢复精确原文；重复升级不额外备份，重复恢复无操作 |
| MIG-003 | 未来模块、设置或日志阻止整批迁移，旧文件保持原字节 |
| MIG-004 | 未来项目或缺少模块身份的数据不能伪装成可迁移旧版 |
| MIG-005 | 预览后编辑、新增文件或跨项目使用 token 均拒绝首写 |
| MIG-006 | 注入中途写入故障，全部文件回滚；备份与事务日志保留，再次打开可检查 |
| MIG-007 | 恢复不覆盖后续人工编辑；损坏备份、未来备份外壳及未来条目版本拒绝 |
| MIG-008 | 备份不能越过项目边界、写入 Git 内部或经过符号链接 |
| MIG-009 | 保存／导入不能用 v1 覆盖磁盘上的未来模块；普通无版本损坏 YAML 仍可显式修复 |
| MIG-010 | 未知未来日志不执行回滚；真实旧 pending 日志先存原文，再恢复前镜像并更新为 v1 |
| MIG-011 | 升级项目原生交换往返保留文件哈希和二进制附件，不携带本机备份 |
| MIG-012 | 跨模块重复身份阻止迁移，不重新编号或分配 UUID |
| MIG-013 | 本机设置首次升级先备份精确原文；并发版本冲突或损坏旧备份时不覆盖 |
| MIG-014 | 十分钟预览过期或检查后出现未解决恢复问题，整批拒绝首写 |
| SCHEMA-001 | 各版本 Schema 离线编译；冻结夹具与当前写入器满足契约 |
| SCHEMA-002 | Schema 拒绝未来版本／错误类型；安全可选扩展仍兼容 |

实现入口：[格式与链式迁移](../tests/formats.test.ts)、[文件迁移与恢复](../tests/migrations.test.ts)、[离线 Schema](../tests/schemas.test.ts)。历史夹具在 `tests/fixtures/formats/`，`.gitattributes` 禁止 Git 自动转换其换行；不能用重新生成夹具掩盖不兼容。

现有核心用例还覆盖边界识别、伪标记、源区间补丁、编辑冲突、路径／大小写约束、文件交换、事务恢复、真实 Git 暂存区保护、项目默认值与工作流，以及真实 PlantUML JAR 和本地 HTTP Server。入口：[core](../tests/core.test.ts)、[git](../tests/git.test.ts)、[project](../tests/project.test.ts)、[plantuml](../tests/plantuml.test.ts)。

## 条目模型

| 编号 | 场景与验收结果 |
| --- | --- |
| ITEM-001 | 标题独立于正文，局部补丁保留 BOM／CRLF 与 UUID，留空使用正文标题，编号补丁拒绝 |
| ITEM-002 | 文本、有限数值、有类型数组及按类型属性校验；v1 保持原全局语义 |
| ITEM-003 | 项目 v1→v2 迁移保留身份、扩展、注释、CRLF；为旧属性建立全部类型绑定；重复执行无操作 |
| ITEM-004 | 在用类型、属性定义、类型绑定不可删除，普通保存不能直接改格式版本 |
| ITEM-005 | 新建编号自动递增；跨模块重复、非法前缀、保存／导入篡改已有编号及数字溢出均拒绝 |
| ITEM-006 | 跨模块类型迁移预览零写入，只替换类型源字段，迁移后可删除原空类型 |
| ITEM-007 | 目标未启用的属性保留并预警；外部编辑、跨项目和过期计划拒绝 |
| ITEM-008 | 多文件迁移中途失败回滚；新增文档使预览失效 |
| ITEM-009 | 两套类型模板离线可用且无重复类型；ASPICE 为参考映射 |
| SCHEMA-003 | 项目 v2 支持数组与类型绑定，v1 Schema 留存，未来 v3 拒绝 |

入口：[条目模型](../tests/item-model.test.ts)。

## 桌面流程

| 流程 | 验收结果 |
| --- | --- |
| 编辑与重启 | 正文、属性、关联、新条目、撤销与视图切换后保存／重启保留 |
| 外部冲突 | 磁盘外部修改不会被静默覆盖，显式保留本地版本才继续 |
| 交换／插件／Git | 交换预览、插件生命周期、实际文件交换与选中文件提交 |
| 项目设置 | 默认编号、状态转换、渲染与导出偏好保存并在重启后保留 |
| 离线技术文档 | 阻断网络时呈现代码、Mermaid 标签、公式字体、JAR、任务、脚注和提示块；本地插件启停可回退 |
| 迁移与未来模块 | 设置页检查／原文预览／升级／恢复真实文件；未来模块强制源码只读；直接 IPC 也不能降级覆盖 |
| 新条目模型 | 套餐、自定义类型、属性表单、独立标题、片段搜索、跨模块类型迁移与在用删除保护，重启保留 |
| 项目 v1→v2 | 设置页显式升级并验证旧属性绑定；原文备份可恢复为 v1，文档字节不变 |
| 未来本机状态 | 未知最近项目原文保留；未知插件状态不执行插件，启用操作被阻止且状态文件不变 |

入口：[桌面用例](../tests/e2e/desktop.spec.ts)。每次修改按影响范围维护这些流程；真实系统输入法、Windows 实机、性能规模和进程强杀验证应单独记录，不用交叉打包或模拟故障替代。

新增业务格式版本时，保留旧版夹具与 Schema，补充真实升级链、各源／目标版本的校验器及迁移后完整交换。协议细节见[数据格式契约](data-formats.md)，执行结果见[v0.1.1 验证记录](validation-v0.2.0.md)。
