## 当前边界

- v0.1 仅支持顶层连续块，不支持需求块嵌套或表格单元格内部的独立条目。
- 格式错误和身份歧义提供源码处理；没有自动的语义三方合并。原生导入按路径预览并校验身份，迁移了路径的同身份模块需先处理冲突。
- CSV 目前由内置插件导出，普通 Markdown 单文件交换不携带附件。
- PlantUML 本地后端需要本机 Java，部分图形还需要 Graphviz；Server 仅在用户选择后使用。复杂 Mermaid 图形和不同 Server 部署仍需实际文档验证。
- 尚无远程 Git、历史文件恢复界面、命名基线、报告导出或团队服务。
- 未保存草稿只驻留会话；退出提醒可避免误关，但不提供进程崩溃后的未保存草稿恢复。
- 单文档 8 MB、原生交换包 128 MB，尚未形成大规模工作区的性能承诺。
- 源码格式切换和普通编辑已验证；并非 Typora 全部排版与交互功能的复刻。

原生交换包的机器可读结构见 [workspace-v1.schema.json](../schemas/workspace-v1.schema.json)；运行时还实施路径、哈希及领域校验。
