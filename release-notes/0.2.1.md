ReqType 是 Markdown 原生的本地需求工作台，支持自动编号、独立标题、类型化属性和跨文档关联。本次完善快速编辑时的焦点保护，并提供 macOS Apple Silicon、Intel 与 Windows x64 的原生验证发行包。

## 更新内容

- macOS 与 Windows 的开发版、发行包均经过原生桌面回归；日常测试默认后台运行。
